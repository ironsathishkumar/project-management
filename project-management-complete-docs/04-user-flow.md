# User Flows

## New User

```text
Register / Login
      ↓
Create Workspace
      ↓
Invite Members
      ↓
Create Project
      ↓
Select/Create Workflow
      ↓
Create Categories
      ↓
Create Tasks
      ↓
Assign Tasks
      ↓
Use Kanban / List
      ↓
Track Progress
      ↓
Complete Project
```

## Daily Member Flow

```text
Login
 ↓
Home / My Tasks
 ↓
Open Task
 ↓
Work
 ↓
Update Status
 ↓
Comment / Attach evidence if needed
 ↓
Complete
```

## Project Manager Flow

```text
Login
 ↓
Dashboard
 ↓
Project
 ↓
Review Progress
 ↓
Check Overdue / Blocked
 ↓
Review Workload
 ↓
Assign / Reassign
 ↓
Review Milestones
```

## Admin Flow

```text
Login
 ↓
Workspace
 ↓
Members
 ↓
Roles / Permissions
 ↓
Projects
 ↓
Workflows
 ↓
Categories
 ↓
Custom Fields
 ↓
Settings
```

## Task Flow

```text
Create
 ↓
Not Started
 ↓
In Progress
 ↓
Review
 ↓
Testing
 ↓
Completed
```

The above is a default example, not a fixed workflow.

## Task Interaction

```text
Kanban
 ↓
Click task
 ↓
Task drawer
 ↓
Edit / comment / update
 ↓
Save
 ↓
Activity recorded
```
