# Project Management & Implementation Tracker — Product Overview

## Vision
Build a simple, user-friendly project management and implementation tracking application inspired by useful concepts from Jira, Kanban tools, Notion, and modern product trackers without copying their complexity.

**Core principle:** Simple by default. Powerful when needed.

## Ecosystem
The application is the first product under a future central application platform controlled by one central owner.

```text
Central Platform
├── Project Management
├── Martial Arts Management
└── Future Applications
```

The central platform will eventually manage application lifecycle, features, plans, pricing, usage, customers, subscriptions, revenue, and analytics. The Project Management application should remain domain-focused.

## Product Rules
1. Keep common workflows simple.
2. Avoid unnecessary configuration.
3. Make statuses, workflows, categories, filters, and views dynamic.
4. Keep system meanings stable even when user-facing names change.
5. Use sensible defaults.
6. Prefer contextual actions and fewer clicks.
7. Advanced features must not complicate the normal experience.
8. Do not build a feature only because another product has it.
